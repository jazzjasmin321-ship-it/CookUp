# CookUp – Recipe Sharing Application

CookUp is a full-stack recipe sharing application where users can create, view, edit, and delete recipes.

The application also includes an admin panel for managing users and recipes.

## Technologies Used

### Frontend

* React.js
* JavaScript
* HTML
* CSS

### Backend

* Java
* Spring Boot
* REST APIs
* Spring Data JPA
* Thymeleaf

### Database

* MySQL / MariaDB

### Tools

* Visual Studio Code
* Spring Tool Suite / Eclipse
* Postman
* phpMyAdmin
* XAMPP

## Main Features

### User Side

* User registration and login
* User profile
* Edit profile
* Change password
* Create recipes
* View recipes
* Edit recipes
* Delete recipes
* My Recipes
* Recipe view counter
* Logout

### Admin Side

* Admin login
* Admin dashboard
* View users
* Block and unblock users
* Delete users
* View recipe details
* View most viewed recipes

## Project Structure

The project consists of:

* React frontend
* Spring Boot backend
* REST API layer
* MySQL/MariaDB database
* Thymeleaf-based admin panel

## Purpose

The project was developed to practice full-stack application development using React, Spring Boot, REST APIs, Spring Data JPA, Thymeleaf, and MySQL/MariaDB.
